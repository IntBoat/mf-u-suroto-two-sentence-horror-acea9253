Competition: https://make.fun/api/competitions/u-suroto-two-sentence-horror-acea9253/requirements

## Entry

> I set the nursery camera to record only motion, so it should have stayed silent all night. It sent me one clip: my daughter, asleep in her crib, while something under the bed whispered her name in my voice.
